# AgentOps CRM (Phase 1 MVP)

Unified Dashboard for Autonomous AI Operation Management.

## Phase 1 Overview
Build a strong local-first MVP with basic views and realistic mock data.

### Features
- **Dashboard**: Stats cards for active/paused jobs, approvals, and failures.
- **Clients & Projects**: Management views for clients and project milestones.
- **Agent Runs**: Detailed table of running/completed agent tasks.
- **Approval Center**: Human-in-the-loop queue for critical actions.
- **Timeline**: Unified activity feed across all entities.

## Setup
```bash
npm install
npm run dev
```
